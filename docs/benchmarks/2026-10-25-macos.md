# Benchmarks — 2026-10-25, macOS 27 (arm64)

`python3 tools/bench.py 3`: median of 3 runs per browser and page. Raw numbers are in
[`latest.json`](latest.json). Pages: the local Blazor WASM [engine probe](../../test/engine-probe)
and [Wikipedia: Web browser](https://en.wikipedia.org/wiki/Web_browser).

| Browser | Size on disk | Time to window | Memory, probe page | Memory, Wikipedia | Processes |
|---|--:|--:|--:|--:|--:|
| **canbec 0.1** (wry / WebKit, full EasyList on) | **4.0 MB** | **0.31–0.33 s** | **434 MB** | **358 MB** | **5** |
| Safari | 34.6 MB | 1.08–1.11 s | 1,056 MB | 976 MB | 10–11 |
| Microsoft Edge | 1,111 MB | 0.64 s | 1,481 MB | 1,963 MB | 13–15 |

**In short:** canbec opens about 2–3× faster and uses about **2.7× less memory than Safari** and
**3–5× less than Edge** on the same pages. It runs the same WebKit engine Safari uses, so the
savings come from carrying nothing extra (no sync, no extensions, no preloading).

## How it's measured

- **Time to window:** from process launch until the first on-screen window owned by that browser
  appears (`tools/firstwindow.swift`, polling every 20 ms). This is *not* first paint.
- **Memory:** the sum of RSS over every process that appeared during the run and belongs to the
  browser (for canbec and Safari this includes WebKit's WebContent / Networking / GPU processes),
  measured 15 s after the window appeared.
- canbec and Edge run with a throwaway profile each time. canbec gets the full EasyList (~24k ad
  rules) copied in, like a real user after the first week. Without it, Wikipedia was 323 MB, so
  the ad rules cost about 35 MB.

## Caveats (read before quoting)

- RSS sums **double-count shared memory** (both WebKit and Chromium share a lot between
  processes). Absolute numbers are too high for every browser; the *ratios* are what's comparable.
- **Safari can't use a throwaway profile**, so it ran with the machine owner's profile. Session
  restore, extensions and history can make it heavier. Treat its numbers as "Safari as people
  actually use it".
- Edge's first run includes a one-time profile setup (3.5 s window time); the median hides it.
- Chrome, Firefox, Zen and Brave weren't installed on this machine, so they aren't in this run.
- Only one machine was tested. Windows and Linux numbers will come from CI runners later.
