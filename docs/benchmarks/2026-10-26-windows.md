[`latest-windows.json`](latest-windows.json). Same pages as on [macOS](2026-10-25-macos.md): the
local Blazor WASM [engine probe](../../test/engine-probe) and
[Wikipedia: Web browser](https://en.wikipedia.org/wiki/Web_browser). Machine: Ryzen AI 9 HX 370,
32 GB RAM. canbec 0.1.0 is the CI build of `d5ba674` on WebView2 155.0.4283; Chrome 155.0.8059;
Edge 155.0.4283.

| **canbec 0.1** (wry / WebView2, full EasyList on) | **4.5 MB**¹ | **0.08 s** | **418 MB** | **367 MB** | **655 MB** | **8** |

**In short:** on Windows canbec runs the same Chromium engine as Chrome (through WebView2), so
memory is **close to Chrome's: about 15% less on Wikipedia and 7% less on the probe**. The macOS gap
(2.7× vs Safari) doesn't show up here. The window opens about 6× sooner, and the app is about 110×
smaller. Edge uses **about 3.5–4× more** than both, because it starts about 13 extra processes
after a few seconds.

¹ Plus the WebView2 runtime (868 MB). It ships with Windows 11 and is shared with other apps, so
canbec doesn't download it.

## How it's measured

- **Time to window:** from process launch until the launched process owns a visible, titled
  top-level window (`EnumWindows`, polled every 20 ms). This is *not* first paint. canbec shows
  its window before WebView2 has started, while Chrome and Edge start their browser core first.
  So this number makes canbec look faster than it really feels.
- **Memory:** summed over the launched process and all of its child processes (for canbec, the
  `msedgewebview2.exe` processes too), 15 s after the window appeared. **Private** = memory only
  that process tree uses (no double counting, the fairest number). **Working set** = closest to
  macOS RSS (counts shared pages again in every process).
- Every run uses a throwaway profile (`CANBEC_CONFIG_DIR`, `--user-data-dir`) with
  `--no-first-run`. canbec gets the full EasyList (~24k rules), like on macOS.

## Caveats (read before quoting)

- **Edge doesn't behave the same on every run.** In the first two probe runs it had 11 processes
  and about 470 MB private (about the same as Chrome). In every later run it had 24–25 processes
  and 1.3–1.8 GB. That's the Edge we ship against, but "Edge is 4× heavier" depends on its
  background features starting within 15 s.
- One Chrome Wikipedia run hit 3.9 GB / 34 processes (a one-time component download on a fresh
  profile, probably). The median of 5 leaves it out.
- canbec's tree has 8 processes because WebView2 runs its own browser, GPU, network, storage and
  renderer processes. Most of canbec's memory is WebView2, not canbec.
- Page speed (JS, layout) is the same Chromium 155 in all three, so it wasn't benchmarked
  separately.
- One machine, one day. Close other heavy apps before re-running, since they change the timings.
